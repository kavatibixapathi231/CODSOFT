# Quiz App

## 📌 Project Overview

Quiz App is a application developed to help users test their knowledge across multiple subjects through interactive quizzes. The application provides a simple and user-friendly interface where users can select a subject, answer multiple-choice questions, and view their scores instantly.

The project is built using Flask, HTML, CSS, JavaScript, Bootstrap, and SQLite.

---

## 🚀 Features

- User-friendly and responsive interface
- 7 Different Subjects
- 10 Multiple Choice Questions per Subject
- Instant Score Calculation
- Dynamic Question Loading
- SQLite Database Integration
- Mobile-Friendly Design using Bootstrap
- Simple and Fast Quiz Navigation

---

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript
- Bootstrap 5

### Backend
- Flask (Python)

### Database
- SQLite

---

## 📚 Subjects Included

The application contains the following 7 subjects:

1. Mathematics
2. Physics
3. Chemistry
4. Computer Science
5. English
6. General Knowledge
7. Biology

Each subject contains **10 questions**, making a total of **70 quiz questions**.
